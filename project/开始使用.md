# 海岸白日梦 · 鹈鹕骑行

## 2026-10-13 本地测试版

这是可以运行的阶段版本，画面还在继续优化，不代表最终交付或已经达到目标画质。

Windows 最简单的启动方式：

1. 克隆这个仓库，或在 GitHub 点击 Code → Download ZIP 后解压。
2. 从 [Godot 官方归档](https://godotengine.org/download/archive/4.6.3-stable/) 下载适合电脑的 Godot 4.6.3 Standard，无需 .NET 版本。
3. 打开 Godot，在项目管理器点 Import，选择仓库里的 `project.godot`。
4. 等待第一次资源导入完成，按 F5 运行。首次导入会自动生成 `.godot` 缓存。

运行不需要 Blender，仓库已包含游戏使用的 GLB 模型。需要修改源模型时再使用 `source/pelican_coast.blend`。详细步骤见 [Windows 本地测试说明](docs/LOCAL_TEST_WINDOWS.md)。

这是重新制作的 Godot 4.6 原生 3D 小场景。用 Godot 4.6.3 打开 `project.godot`，按 F5 运行。

- 空格：暂停或继续
- + / −，或上下方向键：调整骑行速度
- 1 / 2 / 3：明信片、跟随、近景视角
- 鼠标拖动：在展示范围内环绕观察；滚轮：小幅缩放
- R：重置
- F12：保存原生游戏画面，位于 `captures/`

底部控制条也可以点击。暂停时角色、车轮、水面和草木摆动一起停止，镜头仍可调整。这个版本是可以交互观察的骑行小场景，不是开放世界或真实自行车物理模拟；镜头限制在已制作的展示范围内，没有音频。

`source/` 保存可编辑的 Blender 源文件；`assets/coastal_ride.glb` 是游戏使用的模型。角色、车和海岸的可见几何都来自 Blender。Godot 负责分层卡通光影、不同材质的高光、局部细描边、海水接触泡沫、镜头、动画和界面。

普通启动已经启用确认过的近景构图、羽毛纹理、卡通材质、密集植被和悬崖藤叶，无需额外预览参数。

在软件渲染环境中可运行 `godot --path . -- --software-preview --compact-preview`，以 FXAA、较低分辨率阴影和960×600窗口降低开销，保留模型与植被。验证机器使用 llvmpipe CPU 软件渲染，不能据此承诺真实显卡帧率。演示视频若由 Godot Movie Maker 离线逐帧生成，也不代表实时达到视频标注帧率。
