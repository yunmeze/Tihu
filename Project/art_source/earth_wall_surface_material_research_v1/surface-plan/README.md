## 2. 可供人工批准的最小分区

定义二维阅读坐标 `Q = y + 2/3 (x−32)`。斜率 −2/3 来自明确的重复位移，不代表真实屋面坡度、相机姿态或法线。

建议候选线：

- 压顶材料下沿：`Q=267`，即 `(32,267) → (224,139)`。
- 基础材料上沿：`Q=322`，即 `(32,322) → (224,194)`。
- 原支持内，Q<267 归压顶；267≤Q<322 归墙身；Q≥322 归基础。使用同一条共享边，不让相邻带各自拟合。

这两条直线在已读五处中的中心残差均不超过 0.34px，全部落入保守人工区间，但**选择直线本身属于新的二维美术设计选择**。它不声称恢复每一块原瓦齿/托件的语义边缘。

## 3. UV A：先给无结构微纹理一套等密度二维坐标

建议首个最小实验只使用无建筑轮廓、无板缝/柱/大阴影的中灰墙材质。三带方案先完整定义，后续每份材料独立生成；不要一次生成三格拼贴大板再裁开。

设屏幕二维单位轴：

- 沿墙轴 E=(3,−2)/√13。
- 屏幕正交轴 N=(2,3)/√13。
- `s = [3(x−32)−2y]/√13`。
- `n = [2(x−32)+3y]/√13`。
- 周期 `P=64√13=230.7553` 逻辑像素。
- `u=[3(x−32)−2y]/832`，`v=[2(x−32)+3y−420]/832`。

所有 owner 和三材料共享这套**连续全局坐标**。三材料选各自图像，但不重置 UV 起点、不按带高归一化、不把尾片单独 fit。每份建议 1024×1024，采样密度 4.4376 texels/逻辑像素；这是材质板密度，和将来资产 D4 画布1024×1536不是同一概念。

此变换是均匀缩放＋旋转，局部奇异值比=1，不会把金属微纹理拉长 50%。源段有效 v≈0.028..0.820，不需要纵向 wrap；u 跨越多个周期，横向平铺必须真实通过。材料图没有墙体轮廓，因此材料域受固定几何限定是正常表面采样，不是削掉生图新增建筑结构。如果材料生成出墙/檐/台阶/门窗，就在材料原始图阶段退回，不能裁掉结构后称合格。

重复位移 Δ=(-192,+128) 给出 Δu=−1、Δv=0。故数学上保持横向相位；两端是否视觉无缝仍取决于原始 AI 材质的周期连续性和过滤，不能由公式保证。

### “各面原透视”能与不能承诺的内容

- 所有面域、外形、两端、大小和层序停留在原二维投影；没有变换源几何。
- A 方案只保证屏幕微纹理密度相同，不伪称恢复了真实屋面/墙面物理 UV 或法线。微纹理没有宏观几何方向，避免制造与原投影冲突的砖格/板格。
- 原墙身立柱近竖直，屋面瓦向和脊条也不等同于屏幕正交微纹理网格；**不能把本示意网格直接画成正式金属板缝**。
- 若正式金属需要可见折边/立缝，先在源图上人工批准固定二维两轴、板宽、周期、脊条/檐下分面，再使用各面固定的2D材料图/常量UV。禁止用一个被压扁的整墙图反推这些参数。强方向材质的任何特定斜切都必须作为已批准二维设计，而非冒称“无畸变真投影”。
- 独立平面材料不会自动产生屋脊、压顶厚度与檐下明暗。新的二维明暗/结构细节仍需要明确美术方案与AI正式图像；不从旧低清RGB抽出光照乘回去，不用程序线条/渐变/shader花纹冒充新正式美术。

## 5. 不能拉伸金属的禁区

1. 不复用两次失败整墙 raw 做映射母版；共同affine和多带救图继续冻结。
2. 不按压顶/墙/基础各自高度把一整张材料图 squeeze 到0..1，不逐owner改变密度，不在尾片重新起相位。
3. 不添加局部控制点把板缝拉弯，尤其不允许此前压顶约1.5×、墙约0.6×那种相反纵向比例。
4. 不通过镜像、随机段偏移、边缘模糊、装饰条、压低alpha来遮缝。
5. 不把方向高光随UV任意旋转后声称日光一致。微纹理板应弱方向、无整体渐变；真实二维面的明暗由之后批准的美术方案处理。
6. 不因技术可采样就称资产美术完成；轮廓、2D分面、材料、接续、遮挡、引擎验证各自有准入门槛。
