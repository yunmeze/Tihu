Research only. Index18 is isolated by actual 8-bit BMP palette index, never dark-RGB threshold. Selected body counts in phase order: 365,350,313,309,304,329; parity respectively0,1,0,0,1,1. All selected head layers have zero index18. No selected-layer semantic conflict was observed in the full original/excluded/removed board. Removed pixels form the offset checker cast and small foot-adjacent islands. This supports, but does not certify, a shadow interpretation.

Both original packs are independently scanned: body index18 occurs280/281 records, head29/281; every occurring record has a single checker parity. Palette18 is RGB16,8,8 with no duplicate palette entry in these packs. Head-pack use elsewhere is explicitly not generalized to selected head layers.

The decoder/reference rendering code carries baked checker pixels in ordinary RGBA quads. There is no proven original-EXE index18 shadow semantic branch. Consequently outputs remain named index18-excluded-NOT-SEMANTICALLY-CERTIFIED, never guaranteed pure anatomical body. No EXE was run.

For each of12 selected body/head layers, PIXEL_PROOF records original offsets, dimensions, BMP byte locations, all index18 coordinates, original and kept non18 RGBA hashes, counts, decoded and reconstructed RGBA hashes. Assertions verify every non18 pixel is unchanged and keep+removed alpha-composites exactly to decoded original. Original offsets and full128 root16,64 are retained. Both-layer composites match frozen source57–62 RGBA byte-for-byte; composite partition recomposes exactly as well. Alpha is preserved for every kept non18 pixel; only selected index18 alpha is zeroed in excluded analysis and stored separately for reversal. RGB bytes themselves are retained.
