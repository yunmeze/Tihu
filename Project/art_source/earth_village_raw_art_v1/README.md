# Village source art drafts

Forty original PNG art drafts for the Legend village: buildings, characters, terrain, plants, props, fences and dialogue panel. These are project art files, not an accepted runtime release. Some geometry, motion, registration and tiling defects remain. Import is disabled with .gdignore; use the separately documented opt-in preview scene for runtime inspection.

This archive contains only the actual PNG artwork, this short project note, and .gdignore. Generation prompts, tool arguments/results, reference inputs, non-runtime registration/provenance records, tests, diagnostics and temporary files are excluded. No default scene is changed.
