## 造型、数量与支撑的不确定性

原整组是稠密、多个独立细竿组成的竹丛，窄长叶片、小侧枝、清楚节间、前后高低错落，斜俯视，中央较高、边缘较低。不是一棵粗主干阔叶树，也不是7根竹；7指切片数。低分源的枝叶互相遮挡，无法可靠数出隐藏总竿数，故不发明精确植物学总数。生成须逐一追随源图可见竿的分布、密度与下端，不任意减成几根装饰竹或增成竹林墙。

辅助参考去index52后body bbox为(0,0,271,341)，只是可见范围，不是碰撞。原逻辑完整画布319×341包含48px右侧影片。明显最低可见竿端约组内(112,339)，属于321，人工读点误差±3源像素；不是所有竿共用根点。左外端约(34,279)、右外端约(220,247)可作为多点形态比对，误差±4px。多根端点形成有深度的接触带，不是一条可由flag推出的直线；根、地面接触、埋入关系及内部被遮端点均无三维真值。不得用整组bbox下沿或316 cell中心当物理支撑锚，也不得把所有竿底拉平。

生成后应记录至少上述3个及其它清楚可见竿端的对应关系，整体统一density/平移，对整组作一致注册；不用每片独立缩放、旋转、拉伸或bbox归一化救对位。多点无法吻合则重画，不移动源cell、支撑点、碰撞或通路。
