## 原 checker 与投影限制

仅对两个明确空间 ROI 分类，区间为左闭右开：

- 右侧(120,46)..(124,71)：13 个非透明点，全部 RGBA(8,0,0,255)
- 底部(40,100)..(95,105)：62 个非透明点，同色
- 两者都只占奇数(x+y)棋格

右侧外露点相对下缘在右上，可作为很弱的同场方向参照；底部又有向下延展。
这些小外露片不足以拟合精确光向，更不是完整可分离地影。
同一深色在全图有1,075点，从y5到y104，穿插到冠内、叶内和外缘。
**不能全图按该RGB删色、提取完整影，或把冠内暗部当成地面。**
原4张RGBA与合成均完整保留。

## 一幅新图、技术分片与独立单影的可行性

技术上可行，前提是把三件事分开审查：

1. 先生成一幅完整静态RGBA灌木。保留低矮圆形体量、绿叶及黄绿受光叶尖、
   不规则自然叶缘和宽下缘，不做原checker、地块或baked cast。
2. 整株采用共同scale+translation，按原4 owner深度合同做技术分片；没有必要
   生四张或做动画。上缘143必须保留提前排序语义。新增轮廓超出源覆盖的归属
   仍须明确记录，整株/分片GPU parity及actor前后遮挡都要重检。
3. 待新图基部可读、登记通过后，用**完整新图alpha只投一次影**；不对4 cutout
   各投一次。普通runtime路径要包含完整alpha依赖，同组抑制原4片，避免旧
   checker与新影叠加。先审(57,38)一株，其余实例不自动获得遮挡验收。

灌木仍是有深度的体积。未来的平面投影只能是平地2D近似，不能把隐藏根点、
冠内暗部或bbox最低点当作已知3D高度。当前没有选择影参数、改helper或实现影。
