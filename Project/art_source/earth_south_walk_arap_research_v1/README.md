No new art or solver run.

These regenerate intermediate NPZ and reports; they may be expensive and overwrite work reports. Original code/constraints and final NPZ are archived, but no cross-machine floating-point/NPZ byte identity or full end-to-end solver repeat is claimed.
3. **Godot rendering not rerun for archive validation:** External work/south-walk-arap-six-v1/run.sh exports using existing mesh data; preview.sh uses existing finalPNG.
