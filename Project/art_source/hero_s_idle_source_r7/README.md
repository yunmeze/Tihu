- 四帧都是 S 正面站姿，胸口朝前；每帧双手和双靴都可独立辨认。不能继承当前重建 SE 的侧身、头偏转、肩遮挡或单手遮挡。
- 保留 17 → 18 → 19 → 20 四个真实不同阶段。六组 changed pixels 为 385、549、433、392、179、383，顺序见 JSON；18/20 最接近也不是同一帧。20→17 仍差 433 像素，不能用复制首帧封环。
- body 四帧均 64×71，offset (7,-47)；head 四帧均 8×12，offset 分别 (21,-49)、(20,-49)、(20,-49)、(21,-49)。这些是原存储尺寸和绘制偏移，不是人物包围盒。
- 头部始终以正面为主。17 的中段轮廓较宽，18/19 有细小左缘像素差异，20 轮廓较窄；不据低分辨率光影强定 yaw/pitch/roll。四帧冠顶实际上完全固定在 native x39–41、y15，head offset 的 1px 变化被帧内像素位置抵消，不能制造头部整体位移或上下弹跳。
- 肩领、袖口和胸部有轻微表面起伏。19 相比 17 的改动最多，右肩高光区域较短；这些不是整个身体向上或向下平移的证据。
- 两靴白色端点约为 (33,81)、(47,86)，所有阶段分开可见。左侧白色像素簇完全相同，右侧有约 1px 的轮廓变化。屏幕右靴较低不等于已证明承重、落地或重心转移。
