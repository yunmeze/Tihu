1. 当前新环境只有 64 地表、30 楼、35 植物 owner、2 NPC。A13 仍有 2489 地表、1080 静态物件、9 NPC 未换皮。完整源绘制 bounds 核对后，这些未换皮记录均不与固定 Rect(2496,960,768,512) 相交；当前定点截图合格不意味着跟随镜头/整图完成。
2. 不生新图即可进入“候选复用研究”的上限为 28 个完整植物组、103 owner：首树 1、直立树 8、圆灌木 5、两类草各 7。它们共享已用的原 RGBA/crop/相对布局，但仍须逐实例注册和 native 验收，当前授权/注册不自动扩展。
3. 其中 13 组与基线完整 source_cell/flags 相同；14 组 flags 相同而地面字段不同；1 组直立树 (51,70) flags 不同。13 组的周围遮挡和地形也未经同构证明，不能称“无风险全图复制”。所有目标仍保留自己的 source_cell、layer、sort_y、stable order。
4. 最大后续新素材杠杆是源竹组 316–322：20 完整组/140 owner，其次阔叶组 189–195：16 组/112 owner。二者都没有已认可的同源新素材，不能拿现有树改缩放、镜像、涂绿来替代。需在已认可地球基地风格内单独确认源轮廓/owner 组后制作。
5. 地表不能拿 64 块样区 crop 按 frame ID 铺满地图：那是连续位置绑定母版，不是通用 tile 库。要先做与当前母版材料/尺度/左上日光一致的相邻地表连续扩展，保原道路/草边/路缘几何、源 alpha、碰撞和门户。
6. 新阴影许可也不能平移：现有 receiver/gate 有固定 world envelope 和 SHA。新增树、NPC、地表需自己的接收证据；地表 flag 只是逻辑通行/层级字段，不是真实高度。
