## 源契约（不因换服装改变）

样区 world `[2496,960,768,512]` 内这两条原始 NPC 记录的 cell draw origins 为：

- 方丈 record 0，appearance 21、direction slot 2，cell `(64,37)`，world `(3072,1184)`；相位 IDs 261,262,263,264。所有原画布64×69、offset `(-6,-40)`，注册左上`(26,64)`。RGBA 和注册均完全相同，唯一姿势数1。允许只制作一个静态姿势映射这4ID，不添加呼吸、晃动或虚构拳法循环。
- 凌云子 record 1，appearance 9、direction slot 1，cell `(62,36)`，world `(2976,1152)`；相位 IDs 113,114,115,116。尺寸分别60×72、56×71、56×71、56×71；offset `(9,-51),(9,-49),(9,-49),(9,-50)`；注册左上`(41,53),(41,55),(41,55),(41,54)`。4个不同RGBA和动作相，不能复制静态帧或整张平移充当动画。袖/手/衣褶也变化；棋盘影变化不能拿来冒充身体动作。
- 公式 `1+appearance*12+direction_slot*4+phase`。NPC 只有3个存储方向 slot，不能套主角8向方向编号，不镜像。
- 50Hz共享tick；`floor(tick/17)%4`。窗口0–16/17–33/34–50/51–67，单相0.34s，循环68tick=1.36s；进入镜头/互动/换皮不独立重置 NPC 时钟。这是当前/参考实现证据，本次不声称重新追踪原EXE生命周期。
- 原画布像素 `(u,v)` 的world为 `cell*(48,32)+offset+(u,v)`；统一注册画布为 `(32,104)+offset+(u,v)`。未来画布若保持128×160，draw offset `(-32,-104)`；不能再把每相原offset重复叠加。4×纹理每相512×640、root `(128,416)`、绘制scale0.25；最低2×则256×320、root `(64,208)`、scale0.5。
- layer1、sort_y分别37与36、stable source order10000与10001不变。沿用原 `(layer,sort_y,stable order)` 排序；人物前后由这一规则决定，不用 alpha 底端、靴底、贴图高度或新衣服长度决定。主角同y的tie-break也不改。

## 原剧情职责与新视觉设计

方丈原脚本自称“老夫”，说明自己为此处负责人，介绍凌云子引导主角，最终任务阶段引向结局。故“资深/负责训练的教练”是新场景可读的职责转译，而不是更改其剧情职称。原图看得到前屈双臂、不对称屈膝、暗护腕和短靴，不能靠“方丈”二字生成僧袍、胡须、拐杖或坐姿。建议新人物面部显成熟，但不硬加白胡子或精确年龄。

凌云子原脚本负责阶段指引，ET0=2时交代打探任务，再送回A00 `(138,12)` 并设ET0=3，末段让主角找方丈。新设计为基地任务指导员，保持腹前双手交叠和站姿。不能从名字猜性别，也不能把头顶纵向旧冠看成手杖。

父级明确批准：两位按 concept 作为新的成年男性设计，不宣称这是源像素性别/脸型考据。方丈深色无袖上衣、露出的上臂、护腕、深灰训练裤和紧凑护膝/靴；凌云子灰黑有袖短训练夹克、克制肩/前臂护具、独立裤腿和靴。两者都黑短发，但脸型/年龄感/服装轮廓区分；不把NPC变成主角换色同人。

凌云子移除高冠和长袍属于明确批准的外观变化：不得把旧冠顶当头皮顶来拉高真人，也不为保旧袍bbox人为加长腿。使用可见脸/头颈、躯干、手和靴的对应位置约束；旧冠整体上下变化只能做相位提示，不能作为新发顶绝对高度的唯一验收。保留手臂叠放次序和其遮挡关系；旧衣摆遮住的膝部没有足够证据，不编造关节解剖精度。传统挂件不另解释成枪、刀、平板等新增装备。

## 脚根、光照与遮挡门槛

原 `(32,104)` 是绘图原点，不是脚、骨盆或地面。源alpha含烘焙棋盘影，source原图保留该证据，但新主体必须透明、无地影、无脚下黑椭圆、无棋盘。主体自身衣褶阴影保留。

- 方丈原261可见靴区 raw xyxy `[14,49,25,57]`、`[29,59,40,67]`，可见边缘读点误差约±3源像素。不是已解出的精确承重足点。
- 凌云子原113可见靴区 `[4,64,11,72]`、`[19,64,26,72]`，约±2源像素；其他相必须逐相复核，不能把这一ROI直接照搬。原整体可见底变化0,+1,+1,0只是含影可见边缘，不是物理足底证明。
- 旧HD方丈 `(44,118),(61,130)` 是旧候选靴边代理点，不是native事实；其0.706斜脚线及右上cast `(148/279,-111/279)` 不得继承。新左上暖光、右下独立投影与该脚线可能接近平行，未来须独立检查投影矩阵退化、采样范围、全部4相。此次不接阴影，也不宣称平台接收可用。
- 统一暖左上主光、偏冷但不泛蓝的填光；人物转身不能转太阳。未来每个NPC只一份独立落影。存在平台/台阶接收时不能用平地影强装完成。
- 新角色不得压扁/拉高/挪脚救楼体遮挡。主楼原30-owner层级与支撑面保持；画布空白不参与遮挡。禁止为显示NPC把所有建筑放其后，禁止把NPC烧进背景图。

## 分阶段生图建议（下一轮需父级批准实际调用）

1. 方丈先定一个静态新身份全身：输入原完整四相姿态板（说明4个ID是同一姿势）、其concept断开局部、可选主角仅材料局部。产出透明单姿势，原双臂和交错屈膝严格不变，足部保持原相对位置。不是生成4个不同姿势。确认服装/脸/材质与源注册后再复用4ID。
2. 凌云子先以相0姿态+本人的concept局部定一个透明现代身份候选，主要解决去冠去袍后的真人头部与短夹克比例。此单姿势仅是身份母本，绝不标成已完成4相。若父级更偏好减少轮次，可直接一次完整4相，但须接受身份与动作同时失败的风险。
3. 身份通过后，取该母本局部脸/衣料/护具细节，加完整原113–116注册姿态板，一次生成整组4相同装束透明sheet。每相共同画布/同倍率/同平移，不能逐相bbox对齐、补拉伸、独立缩头或脚底齐平。保留袖、手部与身体低幅变化；phase1/2的相同纵向offset不表示姿态相同。
4. QA先看整组原尺寸与2×/4×细节：识别、朝向、脸/胸/腰/靴对应点、手臂遮挡、4相独立差异、脚根漂移、alpha边界、无烘焙影。任何衣服变形换装或动作消失，整组退回；不能只换一相拼凑一致性。运动幅度量化须用可见同类身体点并记录人工误差，不能把衣物点声称为骨骼关节。
5. 注册时保留raw不变，采用一个可审计共同相似变换，不减到128px中间atlas再放大。最终有效细节至少2 texels/逻辑单位，优先4×512×640/相存储；按实际身体面积检查密度，不能凭大空画布合格。凌云子四相最终2048×640的4×画布；方丈可512×640单相重复ID。生成原图主体若低于目标所需真实像素，需重生成，不用插值伪造。
6. 后续runtime另立门槛：PNG→atlas→导入→draw rect→真实截图五处密度；共享17tick循环与原排序；源/新同相位同world对照；主角从两侧与楼门遮挡交叉；整组失败回原资源。此次不实施或报告这部分完成。

生成请求必须写出：真实近未来地球训练基地、实用布料与哑光护具、无袍/高冠/披风/武器/巨肩甲/金纹，非Q版，原游戏俯视斜向视角，无地平线/景深。concept背景与其低分细节不能直接进入新透明资产。
