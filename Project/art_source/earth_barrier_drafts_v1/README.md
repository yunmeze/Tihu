# 地球区阻挡光柱美术首稿

仅归档本阶段实际美术源文件，非正式美术验收。

- `generated-five-phase-sheet.png`：原始生成五相sheet，2025×777 RGBA。五相存在独立形变，未采用为五帧运行素材。
- `fixed-blue-master-8x.png`：从首个蓝槽机械提取并统一等比配准的固定母版，384×736 RGBA，对应完整48×92逻辑画布，亮点锚为原像素(23,67)。

候选方向为统一母版形状与alpha，按原离散色相相位渲染：55,56,57,58,59,59,58,57,56,55；50Hz，每8tick换相。此方案仍待验证。本归档不宣称运行、动画或整体美术通过。

`.gdignore`用于将源稿归档目录排除在Godot资源导入之外。
