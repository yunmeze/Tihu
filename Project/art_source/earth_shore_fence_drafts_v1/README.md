# Shore and fence artwork drafts

Fifteen original PNG artwork files: one unified water material, seven first-pass shoreline families, six fence families and one full-rectangle shoreline experiment. These are source art drafts only, not runtime replacements or accepted assets. Some shoreline drafts have missing areas, mismatched water texture or misaligned joins; fence drafts retain structural and ground-edge differences. The full-rectangle experiment fixes missing opacity but still needs material and geometry review.

This directory contains actual artwork, this note and .gdignore only. Generation prompts, tool records, reference inputs, registration/provenance metadata, diagnostics and tests are excluded. Godot imports are disabled. The published v9 runtime remains unchanged.
