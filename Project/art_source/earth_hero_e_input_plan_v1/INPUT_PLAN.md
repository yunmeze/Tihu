## 坐标、root与密度

原actor绘制原点是世界逻辑O，原层左上=O+offset。这里为方便完整容纳把O放在128×128画布(16,64)，所以画布层左上=(16,64)+offset。例如idle9 body=(31,16)，head=(36,15)。画布点q映回世界为O+q-(16,64)；root不是脚底、bbox中心或物理接地点，不因脚移动改变。

所有相统一裁框[12,8,76,96]，宽64高88，裁后root=(4,56)。idle主板放大6倍后每格384×528，root=(24,336)；walk放大8倍每格512×704，root=(32,448)。这只是最近邻展示源几何，不声称源变高清。加上格原点就是板坐标。完整原图没有逐相裁切、自动居中或归一化。

将来HD4每格512×512代表128×128逻辑，root=(64,256)。从生成raw一次采样到HD4，只用全组一个尺度+逐相刚性平移，禁止旋转、透视、肢体warp、逐相scale、bbox归一化，以及先降到逻辑128再放大。raw有效身体高度/原逻辑身体高度必须逐相>=2，不以整张画布尺寸替代。原E身体冠至最低靴约72逻辑像素：有效raw身体至少约144像素，优选≥288，准确验收按逐相实体测量。HD4画布本身不能证明raw密度。
