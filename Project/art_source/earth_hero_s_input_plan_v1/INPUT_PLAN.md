## 2. 坐标、时序、密度的边界

## 3. 可见代理定义和误差

所有L/R都是屏幕左右，不冒充解剖左右。P=裤褶/裤管轮廓代理(±3px)，C=裤口/靴材料过渡(±1–2)，S=可见靴筒色带(±1–2)，A=趾上靴面收窄(±1–2)，T=靴末端边界(±1)。它们都不是膝、胫骨折点、踝或真实接地点。袖口±3、手部肤色范围±2、冠±1。腿上段被衣服遮住，手近端被袖口遮住；隐藏关节保持null。不得把低屏靴等同承重，也不能由短靴展示长短恢复前后距离。

旧idle数据的boot_tip=(33,81)/(47,86)是亮趾内部代理；本次边界T=(33,83)/(47,87)。两者不是相互矛盾的骨骼测量，更不能混用来产生假位移。新图手套轮廓/指尖不能直接减源肤色小片中心；先选择同类可见区域并记录不确定性。冠相对差会混入头层偏移、发型变化，只能辅助阅读；同时保留公共root绝对坐标差，不把它称为骨骼摆幅。
