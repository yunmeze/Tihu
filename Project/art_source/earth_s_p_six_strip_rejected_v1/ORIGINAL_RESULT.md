## 2. 腰根语义：不能硬套40HD
预先设计 x140..180 是 C 可以覆盖的内部隐藏根区，并未规定完整可见腰/髋宽只能40HD。当前标点实际是完整顶部黑带的左右外缘，黑带下方接整个裤腰；没有可辨的独立窄根台阶/内区边界，也没有证据证明其外缘就是设计内根两端。因此隐藏接口的同名边界未明确交付。

原 AUDIT.json 的 s=.365123824、t=(69.4493,148.4377)、训练RMS5.696HD、持出腰RMS6.079HD，仅是把未确认的边界强作对应后的条件计算；不能作为可用登记、比例结论或“腿过短”的证据。任何40/完整腰带宽的宽度比同样不成立。保留原计算及点文件作历史，SEMANTIC_REGISTRATION_CAVEAT.json 明确覆盖解释；没有另选有利训练点。

顶部黑带厚约24–26raw，只能描述raw结构；在尺度未定前不能据此确认3logical下藏深度。真实覆盖要待可辨接口与合法统一尺度、随后获批组合诊断。

## 3. 透明度：按实际合成贡献
alpha范围0..254；1,292,898/1,572,864像素alpha=0。存在残留，不能称完全干净。以 alpha≥128 主体的欧氏距离测量：
- 距主体≥16raw：1,206,845像素中991个非零，最高alpha1；深底(30,32,36)最大改变0.141色阶，浅底(232,232,232)0.910色阶，均无像素达到1色阶。
- 距主体≥8raw：最高alpha4；浅底最大3.263色阶，46像素≥1色阶、8像素≥2色阶；深底最大0.447色阶。

数值为 straight source-over 各通道最大绝对差，单位8-bit色阶。广域棕黑RGB在忽略alpha的查看方式中可见，不构成大面积不透明背景证据。低alpha远残留保留；未清理。详细可重放脚本 finish_analysis.py 与 FAR_ALPHA_AUDIT.json。

## 4. 最小下一方案（只提案）
1. 姿态参考改为六个同尺度、相同裁窗的源下身放大板，保留57–62顺序；每格明确屏左/屏右可见脚端与投影高低。SOURCE_LOWER_VISIBLE_TERMINALS_8X.png 已制作，仅裁读源像素和标端，不画新腿、不推断被遮骨架。原全窗源作为登记背景记录，避免源小到模型读错59/62。
2. 新接口图需把“隐藏内根”与“可见外腰/髋”分成两个可辨结构。建议真正新绘窄黑连接舌/上延内根，两侧有清楚台阶，内根尺寸只管C遮挡；外腰宽不强塞入40HD。先由父任务审腰根语义图与完整P目标比例，方可定尺度合同；不再把现完整腰带外缘当内根端点。
3. 若批准再生，仍一次生成完整六相3×2strip，不单相补洞、不换相序。材料独立片段板保留；H/C仅作位置比例上下文，不输出。共同密度来自审定完整设计，不由脚终点倒推。收图先审59/62和完整连续链，再识别腰内根；任一语义不清即停止登记。
4. 将来确认接口后，全strip一个scale；各格允许基于同名根中点的整P刚性anchor规范化，所有像素同变换，无非均匀拉伸、无按脚fit。首个合法尺度需腰根之外的独立宽度/完整链持出验证；不拿当前错相图选点求好看。
5. 最终必须以原顺序57→62每相7tick/50Hz（140ms），整环840ms验收，再进引擎和改索引；本次尚未到该门槛。
