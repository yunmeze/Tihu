# 干净源几何重生连续地表方案（仅准备，未生图）

v3实机联合对比仍是满屏卷曲草丝/叶簇，未达到短剪草坪尺度，父级已拒绝替换v2。停止以该草地为底反复局部编辑；本方案从源语义区重新生成完整连续plate，允许重绘路材质，不再同时要求旧路像素不变。

## 三张生成输入，全部排除旧生成草

1. `inputs/source-layout-empty-2x.png`：原源几何语义板的最近邻2×标签图，1536×1024，绿色=草区、灰色=铺装区、洋红=原路缘读数检查带。没有任何草叶、楼、人、树或投影。标签放大不是生成密度证明；真正输出仍须原生1536×1024。
2. `inputs/source-layout-with-scale-actor-2x.png`：唯一运行者以相同语义地表和当前主角做的真实GPU截图，原cell(61,39)、SE13帧，身体核心约144px高，其他物体与投影关闭。人物只作比例尺，最终地表无人无其影。与无人语义图相比仅人物所在区域5620px不同。
3. `inputs/concept-only-material-and-scale.png`：认可概念的纯草纹/绿度及人物尺寸裁图，全部原像素展示；只有概念，没有v2/v3草。它指导细度、平面感、光色，不指导建筑、道路、人物造型或大投影。

**不提交**v2/v3 raw、其草局部、旧概念/当前对照板、原游戏重复草纹全图、完整概念或老场景截图。之前的物体尺度很可能被编辑目标强锁住；此为工作假设，不能保证新生成必然解决。

## 保持什么，允许重绘什么

- 世界范围仍为`[2496,960,3264,1472]`，768×512逻辑；生成1536×1024，原64 owner与alpha覆盖不变。
- 道路方向、封头、底边开口、原6个中心读点与约186逻辑像素的草隙不变；不补通路，不加台阶/花池/凸高路障。
- 原源中心读数约±3逻辑像素；7逻辑像素宽的洋红带是检查带，不是实体路缘宽度或新碰撞。原按floor frame解释的语义边缘有小台阶误差，不能美术化成新装饰缺口。后续仍对照原源和六点审图。
- 全部草和铺装材质允许重新绘制：自然短剪中绿草、微细纹理、平缓低对比色块；路为中性灰工程大板/细平排水边。无需复制v2的接缝纹样和像素。
- 草坪不是苔藓、毛绒、塑料或模糊色面。以人体尺度约束：可读叶尖约1–3输出px、偶见4–6px，多数区域先读成平整安静地面。主角/建筑应承担主要视觉信息。

## 下一次若另获授权

先生成一次独立完整raw，不覆盖v2。核真实尺寸、无人无影/无物体、原六点与路封头/草隙，记录所有布局偏差；随后让唯一运行者做同机位同主角实际1×/2×对比，父级看过后才决定是否做新的64 owner注册。不要把局部放大看上去细腻等同于实机草坪尺度合格，也不要自动继续多轮。
