# 村长 v2 对原 125：统一登记后的表面代理误差

状态：**ANALYSIS_ONLY，v1/v2 均 NOT_ACCEPTED**。此包只读原图和候选，未生图、编辑图片、warp、跑 Godot、写主仓或使用 Git；不代表动作、美术或运行通过。

## 最重要的结论

v2 的主要几何问题是双手明显偏低、偏内。最低材料像素行在主体约 **69.8%**，原125为 **53.7%**；统一登记后，左右手分别低 **10.79 / 10.73 逻辑像素**，分别向内 **4.98 / 3.98 逻辑像素**。手最低行中心间距 **37.03**，原125为 **46**，窄 **19.5%**。即使改变合理 alpha 阈值，偏低结果仍是约10.7–10.9px，结论稳定。

必须统一口径：原125最低手部像素的行索引是36，而该像素下边界是37。前者36/67=53.73%，后者37/67=55.22%。v2相应为69.83%/69.75%的最低行、69.92%/69.83%的下边界。用真正下边界比较时，误差为 **9.85 / 9.79px**，不能把两种口径混算。

## 唯一登记方式

- 源125身体色票代理 bbox `[0,0,49,67)`；原图另含右下棋盘投影，不能当身体宽高
- v2以 alpha>128 的主体 bbox `[226,45,1031,1192)`，宽805、高1147；alpha>0存在很淡散点，不能直接作为人物包络
- 只用一个等比尺度：`s=67/1147=0.05841325196163906`
- 数值映射：`p_source_local=s*p_v2_raw+(-12.09590235396687,-2.628596338273758)`
- 垂直以冠顶边界和最低足部材料下边界登记；水平以两鞋最低材料行中心的中点登记
- 这是坐标运算，没有重采样或输出变形图，没有分头/身/腿缩放、旋转、剪切或分区拟合
- 转到原格点相对坐标，加 `(-1,-47)`；再转世界坐标，加 `(3600,1728)`。格点不是脚底

整个身体宽高比：源 **0.7313**，v2 **0.7018**，仅差约4%。因此只把整体变宽，不能解决手的位置。

鞋最低材料中心距：源17，v2登记17.64，约宽3.8%；左右鞋底材料几乎等高。v2的小鞋尖、布质长衣与近鞋衣摆方向可保留，但这不是最终美术验收。

深色头冠/发体包络：源名义11×8，v2登记12.03×10.34；名义宽+9%、纵深+29%。但它仅是头冠/发体表面，边界范围给出的宽比为0.95–1.26、高比为0.97–1.53。这个证据支持下轮注意头冠体量，**不支持把整颗头机械缩小29%**；脸、下颌、领口在小原图中分界不足以得出精确整头缩放值。
