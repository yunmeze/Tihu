# 地球区主角最小输入计划（待父审，尚未生图）

## 结论

建议先重新定义一张单一SE规范形象，再由它的局部衣甲/头发参考扩原13–16完整4相。旧E/SE/S30相HD4可以复用登记、纹理密度、单影互斥和原子回退技术，不能直接宣布旧服装符合本次认可概念。旧文件保持不变。

已实际查看新概念全图、主角原像素6倍局部、旧identity-rebuild-v2-raw及原source13。新主角仍是短黑发成年男性、黑技术底层、银灰甲与暗红肩，宽泛类别相近；但新概念胸腹和腰更简洁，黑底连续面更大，膝/靴更深石墨，青色身体发光线不突出。旧图大面积亮银角状胸腹板、明显多段银腿甲、酒红膝片、青线和装饰边数量更多。把旧图只压暗/缩小无法建立同一新服装结构，也不能以技术清晰度代替形象批准。

概念的可见主角约60×121像素，头部仅约27×27裁片含背景，脸的实际有效像素更少。可以确认短黑发、成年正常体型、空手、深色技术内层和银灰护具；眼色、精确脸型、五官、面部表情、护甲接缝/紧固件、背甲、隐藏肩膝、具体指套结构不能精确恢复。后续生成应明示为对认可方向的规范化细化，不能声称找回旧批准脸或逐细节复制概念。当前概念手部仅少量肤色/黑块，露指结构的细节为待定项；不把旧手套刻线当新批准事实。

## 选择理由与不确定性

- 单张canonical先锁服装：低分概念不能为逐相生成提供稳定胸腰/靴结构，直接整4容易每帧自行发明细节。先单张可使父级明确审一次设计，降低四相不同衣甲风险。
- 源13负责唯一姿态/机位：原俯视SE、身体倾向、手臂与不对称足位保持。原白衣/裙带只提供动作轮廓，不复制成银环或垂甲。成人比例与姿态尺度在原逻辑框内检查，不用概念整场景人物位置当游戏脚点。
- 新概念负责外观：只提供局部头发、胸黑底、可见暗红肩、胯腿和靴材质。旧生成整人/旧身份碎片不作为输入。
- 真实细化仅限必要连接：石墨银灰贴体护具、黑技术内衬、少量暗红，功能性手套与靴；不得加大光核、遍布青灯、披风、武器、背包、翼、裙甲或繁复皮扣。具体脸部若未从父审获得新指示，保持自然成年东亚面孔和短黑发，不擅认旧脸一致。
