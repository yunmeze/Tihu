# Legend：纯 2D 地球区重建试玩

## 从这里启动

1. 完整下载并解压仓库，保留整个 `Project` 目录。
2. 用 **Godot 4.6.x** 导入 `Project/project.godot`，等待首次资源导入完成。
3. 按 **F5（运行项目）**。当前默认是统一开场 `scenes/earth_new_game_candidate.tscn`。
4. 点击“踏入江湖 · 创建角色”，阅读五页开场，用页面按钮继续。进入场景后，按剧情依次与方丈、凌云子交谈，可进入 A00 海曦村首房。

当前交付是源工程，不需要运行原版 EXE。首次导入会生成本机缓存；不要在导入未完成时把缺资源提示当作可忽略错误。Linux Godot 4.6.3 已做完整源目录冷导入和默认入口启动核验；**Windows 和音频尚未实测**。

## 当前默认入口的操作

- **鼠标左键**：点击可走位置寻路；点击可交互 NPC 交谈，再点击对话选项。
- **按住 Shift**：移动时跑步。尚未重制的方向、动作会使用原素材。
- **Esc**：关闭当前对话。
- **F8**：在 A13 对比本阶段地面与原有地面通道。
- 开场页面用“上一页 / 下一页”等屏幕按钮操作。

剧情 `STOP` 状态会禁止走动，对话仍可用；请按剧情推进解除。这里不提供绕过 STOP 的试玩快捷键。旧样区的相机键、空格停止等说明不应套用到这个默认剧情入口。

## 已接入的局部改进

这是使用 2D 图像、原地图与原层序的地球区重建，不是 3D 场景。当前统一入口包含南向 S 步行六相研究稿、既有其他局部主角动作、部分建筑与植物、水池和草丛、虚云静态身份、小屋及张天师四相等阶段资产。S 六相仍保留上身与动作差异，不能视为完整主角动画验收。

A13 地面当前分为 **907 个草地 owner、24 个协调地面 owner、39 个既有替换 owner**，其余 1,583 个仍走原有地面通道。这些数字不代表全图接缝或所有地表都已完成美术验收。已有新增植物复用覆盖 24 组、81 个 owner，与地面 24 项是不同统计。小屋及其他资产只在各自受约束的来源与支持域内替换；依赖不匹配时按对应合同回源。

旧围墙、竹丛和部分草木、NPC、动作、阴影及后续玩法仍有未完成内容。S 步行影只在已资格确认的接地区使用；不能据此声称所有朝向、建筑立面、水面或整图阴影完成。原地图几何与碰撞不因这些画面替换而自动改变。

当前自然流程的边界是创建角色、五页开场、开场双 NPC 剧情与 A00 首房。兼容随机算法尚未复原原 VB 随机序列；保存、战斗、怪物 AI 和后续任务尚未完成。独立研究的 A00 玩法核心、药师购买界面等也**尚未集成为这里的可玩功能**。

## 目录不能随意裁掉

`art_source` 保存生成原图、实际输入、研究合同和重建资料，其中部分 PNG / JSON 仍被运行时按原字节读取。`tools` 保存构建、原始数据核验和受控打包工具，其中也有运行资格校验所需的 Python 源字节。

这两个目录的 `.gdignore` 用于隔离编辑器资源扫描，**不表示目录可以删除**。运行时的 `FileAccess` / `Image.load_from_file` 与哈希校验不依赖它们显示在资源面板中。请勿只复制 `scenes` 和 `assets`，也不要把工具模板直接启用为编辑器插件；受控打包工具会把所需插件安装到独立工程的 `addons` 目录。
