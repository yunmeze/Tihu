# 单树阴影与南侧纹理共享阶段

## 当前范围

F5 默认剧情入口与 F6 当前美术检视接入 A13 的 (51,70) 单树阴影。另一棵 (40,72) 树仍是研究稿；此次不代表整图阴影或高清美术完成。

这棵树保留完整生成图透明度和既有植物层序。影子只落在已核验的地面接收区；水池整体透明轮廓及草边另留五个逻辑像素的保守排除区，因此池边仍可能有空隙。这不是精确石沿或水面受影实现。

南侧共享纹理改为受控加载与弱引用复用。不同地图实例使用独立资格凭据；旧实例释放不应撤销新实例。加载时核验完整 RGBA、空 owner、原资源身份及当前代次，失败按对应资源合同回退。这个约束不覆盖外部任意修改 ImageTexture 内容；已保留的 Canvas 绘制命令也不会因外部重置自动重画，需要正常刷新或请求重绘。

## 已完成验证

- 新运行分支 headless 检查 388 项通过，包含自然 B6 → A00、ET28 → 3 → 28、多地图同纹理独立凭据、重置、伪造凭据与释放。
- 独立打包及八个 headless 阶段共 9,333 项检查通过。新 PCK 含 849 个文件，逐项核验 438 个原始资源依赖；源工程和包内实际入口、50Hz 配置及状态一致。
- Linux Godot 4.6.3 的六个独立原生窗口进程共 9,598 项检查及 48 次渲染读回通过，全部正常退出。源与打包结果的对应状态及 RGBA 相同，显式重绘后的回退与恢复亦逐像素一致。
- 原生渲染环境为 Mesa llvmpipe 软件 OpenGL，经过实际 RenderingServer 绘制，不是硬件 GPU 测试，也不是 headless 图像模拟。
- 四张正式视口图使用 1024×768 逻辑内容和 2048×1536 内部栅格；其余部分为 1152×832 诊断视口。正式开关影子对照改变 61,369 个 RGB 像素，透明度不变；源工程与包内结果一致。
- F6 更新单独验证，具体操作与本轮结果见 CURRENT_ART_REVIEW.md，不能用历史 F6 的检查数替代新版本验证。
