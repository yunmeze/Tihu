这是可选的整村美术预览，不是最终美术或完整第一关验收。请使用包含本检查点的完整 Legend 仓库，不能只下载源素材目录。

## 打开方法

1. 使用 Godot 4.6.x 导入仓库中的 `Project/project.godot`，等待首次资源导入完成。
2. 打开 `res://scenes/earth_overall_village_preview_v9.tscn`，按 F6（运行当前场景）。按界面提示创建角色、阅读五页开场，经过 A13 原双 NPC 剧情后进入海曦村 A00。
3. F5 保持原默认场景 `res://scenes/earth_new_game_candidate.tscn`。此前 v5 检查点仍可从 `res://scenes/earth_overall_art_review_v5.tscn` 按 F6 打开。

如果出现缺资源或校验错误，请核对完整仓库，不要绕过校验。部分美术校验失败会回退原图，窗口能够打开并不代表新美术已经加载。
