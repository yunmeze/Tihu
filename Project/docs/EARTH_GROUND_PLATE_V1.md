## 1 最小范围与真实密度

首轮只做 world 半开范围 **[2496,960,3264,1472]**，即 **768×512 逻辑单位 / 1536×1024 实际纹素**。这是一块唯一连续 plate，不是一套可无限循环地砖。四边对齐原 96×64 FloorBig 完整图块，包含 64 个源 owner，覆盖 alpha 全为 255。原逻辑 cell 是 48×32，不能把 FloorBig 缩成一个 cell。

范围包含原主角起点 `(61,39)` → world `(2928,1248)`、道路封头、左门/左梯及邻近草地。左门可见框约 world `[3191,978,3234,1100]`，在此范围内。主馆仍按完整 30-owner 组设计；首块地表无需为展示右门扩大。右门、右梯、另一侧通路、原全图均保留，不属于本轮地表换皮。

此范围替代早先审查的 1056×832 大候选。大候选及其东北洞口留空方案不作为当前制作范围。父任务提议的 768×512 量级已保留，横向改为源 96-pixel 对齐，避免半块 source owner 导致范围额外增大。

1536×1024 必须是实际生成/注册后的有效画面，不能把低密度图放大到此尺寸后宣称 2×。读取实际 raw 尺寸并计算 `min(raw_w/768, raw_h/512)`；不足 2 时重做或另行缩小制作范围，不改变原世界尺寸。若 raw 有留白、边框或 overscan，应先扣除再算密度。保持单一等比采样，不允许分别拉伸 X/Y。

整场实际绘制仍遵守 Art Bible 的 1024×768 逻辑视野 → 2048×1536 物理输出。此 plate 只覆盖局部，不要求修改默认角色起点、跟随镜头或限制角色只能走这一块。可以明确标注一个局部审图框；框外保留源资源，不能声称全屏已换皮。

主要产物：

- `source-floor-native.png`、`selected-floor-native.png`：768×512 原 floor 组合，不含人物、建筑或其影。

### 坐标与原几何

World +X 向画面右，+Y 向画面下。floor 起点=`cell*(48,32)+frame.crop`，忽略 frame.offset，不用对象的 `32-original_height` 顶部修正。该源网格不是另造一套标准等距菱形变换。

原道路从左下往右上约沿 `(3,-2)` 伸向封头。封头上边近水平，右上短斜边、右侧短竖边、右下斜边必须保留。原读路缘中心 world 点：`(2687,1377) → (2880,1249) → (2976,1251) → (3020,1278) → (3020,1347) → (2932,1408)`。原人工读值约 ±3 逻辑像素；相同原 frame 的重复边界只复用几何解释，不复用新美术纹样。语义 mask 是制作引导，不能包装成精确测绘；其紫色窄带必须对原 RGB 复核后才能定最终路缘细面。

原铺装封头最右约 x3020，左梯下缘 x3206，两者相隔约 186 逻辑单位。中间是原草地及建筑自带裙边，不是贯通铺装。只可把原土/砂路材质换成现代浅灰训练路，不能把草地补成一条新直路。概念里的中央宽阶、抬高花池、沟槽和栏杆不提供新碰撞或拓宽许可。

左梯地边 S0 `(3206,1185)` ±5、梯顶 S1 `(3179,1097)` ±5；左可见门槛 D0 `(3212,1083)` ±8。plate 2× 像素坐标分别为 S0 `(1420,450)`、S1 `(1366,274)`、D0 `(1432,246)`；主角 actor origin 为 `(864,576)`。D0 是可见门槛样本，不是 portal 或寻路目标。主馆右梯 S2/S3、前柱 C0 的原数据仍存在于 contract，只是位于本 plate 外。

六个本区原 layer-0 支撑格 `(66,34),(65,35),(66,35),(65,36),(66,36),(66,37)` 均从 `(61,39)` 静态可达。离线检查使用禁行 flags `-1,-2,-3`、斜行两正交邻格均可入，匹配原 movement 图规则。它不是 Godot A* tie-break 路径、实机步行或剧情解除 STOP 的证明。脚掌相对 actor origin 的偏移由角色相位决定，不以源 cell 点假装脚底已贴合。

## 3 美术分层：一份唯一连续地表

以 `EARTH_ART_BIBLE_V1.md` 和已认可 concept 作材质、颜色、同一日光参考；以本目录源布局作几何权威。优先由同一个约束母版提取地表，不分别生成64张图，再逐格随机补丁。

1. **基础地表 RGB**：整块连续草地与混凝土路面，先做统一漫反射/低频明暗。草地在屏内有唯一的大块疏密、湿干变化和细草层次；路面有少量连续大面板接缝、轻微磨损。面板斜向遵循原道路方向；不画重复一格一格的小砖。禁止镜像草斑、256/512 周期世界 repeat、旋转带光材料、每 owner 随机色差。
2. **材质边界 guide**：草与铺装各自可独立审核，但共用一个 canvas、一个世界原点、一个光照。最后色图仍是一份连续 RGB；草叶细边可以在既有路缘窄带内细化，不移动整体道路边界，不新增花池高度。
3. **静态环境投影/接触影**：独立透明层；其来源是完成注册的主馆整体，且只生成一次。地表 RGB 不烘焙屋顶、人物、树冠、栏杆大投影；不把旧建筑棋盘影复制进新地表。草叶、砂砾等微尺度自阴影属于材质，可保留。
4. **建筑/台阶/前景**：地表不拥有楼身、平台、台阶、侧颊、立柱、前景树或灌木。它们按建筑/对象各自源 owner 与排序制作。禁止把整张有楼有人有树的概念剪成背景，以交互角色在上面移动冒充复刻。

无新远景树库、路灯阵列、训练器械、独立高花池。若主馆资产尚未注册，不为使草地“接上”建筑而描新门路或改草地为高台。

## 4 采样、切片、alpha 与接缝

母版坐标：`raw_pixel_center = 2*(world-[2496,960])`，等价地 `world=[2496,960]+(texel_index+0.5)/2`。原 source 每个 96×64 owner 对应同一母版中的 192×128 区域，不做逐块缩放、旋转或随机偏移。RGB 只从真实高密 raw 直接采样一次，不通过旧 1× atlas。

运行接入阶段仍按64个原 floor owner 的顺序读取同一纹理的区域，或由同一母版导出64个完整注册切片。前者更容易保持连续采样；不能仅因为是一张 plate 就丢掉原 owner 身份。原版相同 signed ID 在不同世界位置会读取不同新 RGB，这正是消除屏内循环纹理的措施，不能用 ID 级全图替换。

本区64块实测各像素 alpha=255，拼接覆盖无缝且无重叠。2× alpha 是 source alpha 精确最近邻扩展，不从新图颜色/草mask推断，不对原透明度做阈值化或重算。这只对本区成立，不能推广到全图 FloorSmall、半透明边或无 floor cell。

如使用 linear，应从共享母版取相邻纹素，或为每片提供来自相邻世界位置的 2–4 纹素 gutter，并用精确 UV 限定有效区域；不能把边缘向内重复、补透明黑，再认为线性采样会无缝。gutter 是采样数据，不扩展 owner 可见覆盖。禁用不受控 atlas shrink/mipmap；最终以实机 1:1 和移动截图决定滤波，不能用糊边遮缝。

验收112条内部边：与整张母版绘制比较，检查边界±4实际像素带；RGB允许自然变化，但不能跳色、出现透明线或纹理重置。原/source切片再组装已 byte-exact；新图切片与 GPU 一致性仍未验证。真正2×导入后还要查PNG、atlas、Godot纹理、draw rect、截图五处尺寸。

外边不是无缝循环边。本轮周围仍是源图，局部审图必须标出范围，不能把外部源/新风格接缝掩盖成全屏完成。将来扩下一块时，冻结本块临边 32 逻辑单位的原 RGB 作为条件/对齐证据，生成相邻唯一内容，使用同世界密度和不少于32逻辑单位的匹配重叠带；连续光照/路缘通过后只保留一份最终母版像素。不绕回本块，不镜像接边。首块先通过再扩，不预制全图模块库。

## 5 阴影接收与遮挡的可行边界

共同主光来自画面左上，投影向右下，精确向量/软硬在工作母版锁定。不能继承旧 shader 的右上投影参数。基础地表不能有互相矛盾的独立太阳高光。

顺序是 floor → 一份平地静态投影 → 原支撑面及原对象/人物流。投影 alpha 只在 `flat-receiver-envelope` 内有效，碰到本 plate 边界就裁切；不能为完整投影扩大首样范围。建筑原支撑面随后遮住地面影，不把地面影抬到台阶或墙上。若需要向未换皮地面延伸影，需另列范围验收，当前不作承诺。

源建筑草石裙/棋盘影属于建筑原子替换检查，不能由地表独自删除。不允许旧棋盘影+新cast双影。主馆新组或投影依赖未齐时，保留完整源组并关闭相应新cast；新 ground 不能声称已经统一了仍未重制对象的光照。

首轮只承诺可制作的平地接收。台阶/平台 shadow receiver 需要建筑提供确切支撑面mask，并在各高度/层级验证；未验证时关闭平台人物影，保留原移动，明确记录缺口。环境影投到行走人物身上也尚未实现，需要另验 actor receiver；不能把整块地影当屏幕前景画在人物头上。前景墙、柱、栏杆严格按原 owner/depth 遮挡，绝不使用整楼一张前景遮罩遮住脚。
