# Legend 重建美术基线

工作基线：2026-10-15。目标是干净、清晰的科幻修炼题材纯 2D 美术。此页约束当前重建，不宣称找回了旧的已批准设计图。

## 画面与材质

- 保留原地图布局、镜头关系、人物动作、碰撞和前后遮挡设计。美术更新不能偷偷改变可走位置或动作阶段。
- 主角：成年东亚男性、短黑发；银灰/黑色贴身分段护甲，酒红肩盖和膝甲，少量细青色接缝，黑色露指手套，空手。无新增披风、背剑、翅膀或大光核。
- 建筑以已选 A13 主寺楼为工作参考：清晰银灰石材、深灰屋面、克制暗红结构、暖门内光和极少青光。保留双门双阶、台基与复合屋顶的识别特征。
- 植被保持自然形态；首棵金黄树使用清楚的叶簇和树皮。不要为了题材给每棵树加机械件或霓虹。
- 地面仍是原有低饱和草地、浅压实土路和窄石边。不要改成金属路或整片银砖。避免亮黄叶片地毯、粗大碎石和周期性暗花。
- 细节服务于原尺寸阅读。减少高频脏点、过曝亮点、杂乱挂件；不能只在放大的原图中显得精细。

## 人物与动作

- 先核原完整相位、方向、偏移、实际可见手脚和相邻接点，再生成整组。不要镜像代替另一方向，不按裁框顶端或每帧包围盒缩放。
- 原源姿态画布是动作与机位的主参考。身份参考使用方向匹配的局部材质/面部片段；不要用失败的完整新人物图再次诱导原有错误姿态。
- 保留不可变 raw、实际 prompt、输入哈希、共同尺度和配准依据。允许技术裁切、统一等比采样、刚性平移、图集和分层；不靠局部扭曲、拉腿或逐帧拼换掩盖动作问题。
- 原四相完全一致的 NPC 可让四个源索引共用一个新静态姿态，保原计时，不凭空制造呼吸。源四相不同者仍需完整组检查。
- NPC 按实际原图，而非称谓刻板印象设计。不能仅因名为方丈就改成僧袍，或把名为混元之气的持杆人形改成气团。原名字、剧情功能不因换美术而改写。
- 背部护甲尚需单独定义后再生产背向；正面肖像不能诱导背向人物回头露脸。

## 光影与分层

- 原图和已选角色使用屏幕右上方向的地面投影参考。当前 shader 是有明确边界的 2D 近似，不宣称物理光照或阶台接收面已复原。
- 每个选用主体只保留一份新地影；抑制相应原棋盘影，失败时完整回退，不能两份叠加。
- 身体、树干、树冠、楼梯和前景栏杆继续使用原 owner 的层级及排序语义。不能为露出脚而把真实前景侧颊降到地面层。
