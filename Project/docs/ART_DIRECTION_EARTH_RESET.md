# Earth-era visual direction reset — 2026-10-15

The user rejected both the earlier low-density presentation and the later 2048×1536 courtyard candidate. Higher raster resolution fixed a real detail-loss problem, but did not resolve the visual direction. The user explicitly chose the Earth era of Swallowed Star.

## Active design target

A near-future Earth base-city martial training facility: grounded human-scale technology, black/gunmetal structural masses, broad horizontal overhangs and diagonal supports, restrained cyan functional lighting, concrete training surfaces, realistic green landscaping, and practical combat/training equipment. Avoid medieval temple decoration, gold-heavy fantasy robes, broad gold-autumn landscaping as the main identifier, alien spaceports, and oversized neon effects.

The original map layout, navigation, entrances, character positions, gameplay and animation timing remain authoritative. The opening protagonist remains unarmed. The project stays pure 2D; high-fidelity pre-rendered-looking artwork is generated as images, not substituted with Blender models.
